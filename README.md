# Blood-Princess

Blood Princess is a First Person Hack'n'Slash Roguelike. 

The princess must climb the tower annihilating anything who stand in her way, using her comically large sword. Slaughter hordes of goblins, ogres and other vermin. Reach the top, defeat the evil wizard and rescue your beloved cat.

The game and its custom D3D11-engine was created during the university course 'Small Game Project'.

You can download the game on [itch.io](https://johannled05.itch.io/blood-princess).

## Build Steps

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Winroth13/Blood-Princess.git
   cd Blood-Princess
   ```
2. **Open the project**:
   - Open `BloodPrincess.slnx` or `BloodPrincess.vcxproj` in Visual Studio 2026.
3. **Configure & Build**:
   - Select configuration: **Release** or **Debug**.
   - Select platform: **x64**.
   - Build the solution (`Ctrl + Shift + B`).
4. **Launch**:
   - Run the executable from Visual Studio (`F5` or `Ctrl + F5`) or launch `BloodPrincess.exe` from the output directory.
